Le déroulement d’un projet

  1. Analyse

    Nous étudions votre entreprise, votre public et votre style visuel, ou vous nous envoyez un brief.

  2. Aperçu

    Nous créons le site et partageons un lien d’aperçu clairement marqué comme démo.

  3. Révisions

    Vous envoyez vos modifications. Nous appliquons les révisions convenues dans la limite des tours de votre formule.

  4. Validation

    Vous confirmez la version finale.

  5. Paiement

    Paiement après la validation finale, avant la livraison et la mise en ligne.

  6. Livraison

    Vous recevez le site propre, sans mentions de démo, ainsi que son code source.

Questions

Dois-je payer avant de voir le site ?

Non. Vous voyez d’abord le site. Le paiement intervient après la validation de la version finale, et avant que nous remettions le code source et mettions le site en ligne sur votre infrastructure.

L’aperçu est-il mon site officiel ?

Non. Un aperçu est une proposition commerciale de SpectrTech, clairement marquée comme démo. Il ne devient votre site qu’après validation et paiement.

Le nom de domaine et l’hébergement sont-ils inclus ?

Non, sauf accord séparé. Vous payez directement les fournisseurs ; le montant réel dépend des fournisseurs choisis.

Y a-t-il un abonnement ou un support obligatoire ?

Non. Vous payez une seule fois pour le travail convenu. D’autres modifications peuvent être discutées comme un projet distinct.

Puis-je modifier le site moi-même ?

Le site est livré sans éditeur intégré. Vous recevez un code source propre, que vous ou n’importe quel développeur pouvez modifier.

Créez-vous des sites multilingues ?

Oui. Les langues sont définies dans le brief, et chaque version a sa propre adresse et ses propres métadonnées.

Parlez-nous de votre entreprise. Nous répondons par des questions ou une proposition, sans engagement.
