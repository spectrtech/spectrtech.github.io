How to use this moving checklist

Start at the block that matches how far away your move is and work down. For a long-distance or international move, start each block a few weeks earlier — the order stays the same. The reasoning behind each step is in the 8-week moving guide, and the box system is in how to label moving boxes. Not sure how many boxes to buy? Use the moving box calculator.
